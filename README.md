# NIGHT WINDOW — Graveyard Shift

A browser cashier-window horror game. Rebuilt from the earlier Night Gate prototype around a glass-sided overnight gas-station cashier booth.

## Play

Open `index.html` in Chrome, Opera, Edge or Firefox. The game is in one file, with no framework or server requirement. An internet connection is optional for Google Fonts; game logic and artwork are inline and run offline.

## How to play

- Read each visitor's order ticket and click shelf products to scan them into the register.
- Click **Fuel Pumps** to select the correct pump (1–4) and authorize the exact amount requested by customers prepaying for gas.
- For cigarettes, click **Check ID**. The sale requires the customer to be at least 21. One visitor is underage and must be refused.
- Click **Ring Up Order** when the scanned products and fuel exactly match the request.
- For cards, approve payment. For cash, type the exact change shown by the register (e.g., `5.25`).
- Repeat through 18 scripted customer encounters across 3 shifts. Odd things start happening later in the week.

## Features

- Detailed, original hand-authored SVG gas-station illustration with rain, reflections, nighttime canopy lighting, pumps, window glass and booth framing.
- Original customer portraits with different clothes and colors and subtle animation.
- 8 uniquely illustrated products, cart/remove controls and pricing.
- Gas prepay for pumps 1–4, cash/card checkout and change verification.
- ID checks, an underage tobacco sale refusal, supervisor notes and story beats.
- Three shifts, 18 visitors, summary and replay. Responsive layout.
